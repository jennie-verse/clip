Make a Shortcut

Copy → run the Shortcut → saved automatically. Set it up once.

1 · Build the "Add to Clip" shortcut

  1. Open the Shortcuts app and tap + in the top right.
  2. Add Get Clipboard.
  3. Add URL Encode. It makes the copied text safe to carry inside an address.
  4. Add Text. Type this address, then insert the URL Encoded Text variable right after the “=”.
    …
  5. Add Open URLs. It opens that Text.
  6. Save it as Add to Clip.

2 · Register a way to run it (pick one)

  • Home Screen — Share → Add to Home Screen
  • Back Tap — Settings → Accessibility → Touch → Back Tap → Double Tap → Add to Clip
  • Control Center — Settings → Control Center → add Shortcuts

3 · Using it

  1. Copy some text in any app.
  2. Run Add to Clip. Clip opens in Safari and saves it by itself — you will see “Saved.” Then switch straight back.

4 · Also from the Share Sheet (optional)

To save the item you share instead of whatever is on the clipboard:

  1. Open the shortcut, tap Details and turn on Show in Share Sheet. A Receive … from Share Sheet card appears at the top.
  2. On that card, tap Continue and choose Get Clipboard. A run without a shared item then uses the clipboard.
  3. Delete the Get Clipboard action and set URL Encode to take Shortcut Input.

5 · Long text (two taps)

The web server refuses addresses longer than about 8,000 characters — roughly 900 Korean or 6,000 English characters — unless Clip is already installed in Safari. If a long clip does not arrive, copy it again and tap Paste from clipboard in Clip, or make a second shortcut with just Open URLs set to this address:

…

It opens a Paste sheet: tap Paste from clipboard, then Paste on the small bubble iOS shows. iOS never lets a web page read your clipboard by itself, so this route cannot save automatically.

Good to know

  • A Shortcut built with Get Clipboard + Copy to Clipboard + Open URLs on the Paste address cannot save by itself — iOS asks for those two taps. Rebuild it as in step 1 to get automatic saving back.
  • The Shortcut opens Clip in Safari, not in the Home Screen app. Turn on Sync, or use Import from the other mode in Settings, to see those clips in the Home Screen app.
